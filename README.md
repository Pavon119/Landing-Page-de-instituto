# Instituto Superior Alma Fuerte - Landing Page

Sitio web institucional desarrollado para el **Instituto Superior Alma Fuerte**. Presenta la oferta académica,
información institucional, canales de contacto directo y acceso rápido a redes sociales.

##  Tecnologías utilizadas
* **HTML5** (Estructura semántica)
* **CSS3** (Diseño responsivo y estilos personalizados)
* **JavaScript (Vanilla)** (Lógica del menú móvil interactivo, accesibilidad y efecto scroll)

## 🌐 Despliegue
Proyecto alojado y optimizado para su visualización web mediante Vercel.
